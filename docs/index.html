案例记录原则

案例页不是营销摘要，而是面向工程复用的可审计说明。

来源冻结记录论文、方程、参数和输入版本，避免目标在执行中漂移。
执行留痕记录求解器版本、运行矩阵、日志、产物与哈希。
门槛先行在看结果前声明守恒、收敛、误差和物理域约束。
独立复核Reviewer 与产出 Agent 身份隔离，并保留退回原因。
